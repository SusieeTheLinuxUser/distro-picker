# DistroPicker

A quiz that recommends a Linux distro based on your hardware, GPU, and experience level — plus an install guide, a distro wiki, and a community leaderboard.

**[distropicker.com](https://distropicker.com/)**

## Features

- 9-question quiz → personalized distro match
- Explore distros and browse a Linux wiki
- Step-by-step install guide
- Community leaderboard and comments (Google sign-in)

## Stack

Single-file static site — HTML, CSS, and vanilla JS in [index.html](index.html). No build step, no dependencies.

## Running locally

```bash
python3 -m http.server
```

Then open `http://localhost:8000`.
